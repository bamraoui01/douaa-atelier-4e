# L’Atelier de Douaa · 4e année

Un nouvel espace d’apprentissage indépendant de « La classe de Douaa ».

18 activités originales, 72 questions corrigées, deux récits de lecture, cinq univers et des badges de progression. Les progrès sont enregistrés uniquement dans le navigateur de l’appareil utilisé. Aucun compte ni service de suivi. Aucun document scolaire personnel dans ce dépôt.

Contenu de consolidation à adapter avec un parent aux apprentissages de l’école ; ce site ne remplace pas un programme scolaire complet.

## Utilisation

Ouvrir `public/index.html` ou publier `public/` avec le workflow GitHub Pages. Les polices distantes sont facultatives et disposent de polices de secours.

## Ajouter une activité

Ajouter une entrée dans `public/lessons.js`, avec un identifiant unique, une matière, une fiche explicative et des questions à choix multiples. `answer` est l’index de la bonne réponse, en commençant par 0. Mettre à jour le nombre d’aventures dans les cartes de matières si nécessaire.

L’ancien site reste à https://bamraoui01.github.io/class-douaa/.
